# 🌟 Overview

UFIN (**Unified Farmer Intelligence Network**) is a full-stack AI-powered agriculture platform that modernizes the farming ecosystem by connecting farmers, buyers, and consumers through one intelligent digital platform.

The application combines Artificial Intelligence, real-time analytics, secure authentication, multilingual support, and marketplace technology to simplify agricultural operations while improving transparency, productivity, and accessibility.

Whether it's analyzing produce quality, tracking batches, monitoring market prices, or enabling direct farmer-to-buyer transactions, UFIN delivers a complete smart farming ecosystem.

# ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/pushpakpogiri111-stack/UFIN-FINAL.git
```

### Navigate to the project

```bash
cd UFIN-FINAL
```

### Install dependencies

#### Frontend

```bash
cd ufin_new/client
npm install
npm run dev
```

#### Backend

```bash
cd ../server
npm install
npm start
```
